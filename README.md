## 📌 Overview

This project presents the 3D CAD modelling and assembly of a **Universal Joint (Cardan Joint)** used for transmitting rotational motion between two shafts that operate at an angle.

The assembly was designed in **SolidWorks**, with focus on component modelling, mechanical assembly, geometric relationships, and rotational motion.

---

## ⚙️ Working Principle

A universal joint allows rotational motion to be transmitted between two intersecting shafts while accommodating an angular misalignment between them.

The joint uses a **cross-shaped spider** connected to two yokes. As the input shaft rotates, the yokes and central cross transmit the rotation to the output shaft.

### Main functions

- Transmits torque between angularly misaligned shafts
- Allows relative angular movement between shafts
- Maintains mechanical connection during rotation
- Commonly used in automotive and mechanical power-transmission systems

---

## 🔩 Main Components

The CAD assembly consists of:


- **Input Yoke**
- **Output Yoke**
- **Cross / Spider**
- **Bearing Caps**
- **Shaft Connections**
- **Retaining / Fastening Features**
